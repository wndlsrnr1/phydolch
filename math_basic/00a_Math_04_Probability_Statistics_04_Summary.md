# 5. 핵심 요약
---

## 이번 단원에서 배운 내용

이번 파트는 "확률 → 정보 이론 → MLE → 손실 함수 → PyTorch 구현"으로 이어지는 한 줄기의 흐름이었습니다. 각 단계가 다음 단계의 토대가 되며, 마지막에는 코드로 연결돼요.

### 1. 확률의 기본과 수학적 엄밀성
- **확률의 공리 / 확률변수 / 기댓값, 분산**: 모든 이론의 공통 언어
- **독립성 가정**: 우도를 곱으로 분해해 MLE를 적용할 수 있는 근거
- ➡️ 다음 단계에서 우도 $P(x_1, \, ..., \, x_n | \theta)$를 세울 때 사용

### 2. 정보 이론 (Information Theory)
- **엔트로피**: 불확실성을 수치로 표현 → 모델의 예측이 얼마나 모호한지 측정
- **KL 발산 / 교차 엔트로피**: 두 분포 사이의 "거리"를 측정
- ➡️ 분류 손실 함수(CrossEntropy)가 단순한 수식이 아니라 정보량 비교라는 사실을 이해

### 3. 확률 분포 (Probability Distribution)
- **정규분포 / 이항·다항분포**: MSE와 CrossEntropy가 기대는 분포 가정
- **68-95-99.7 규칙**: 정규분포 가정을 시각적으로 이해
- ➡️ 손실 함수 유도의 출발점이 되는 가정들을 정리

### 4. 최대우도 추정 (Maximum Likelihood Estimation, MLE)
- **우도 & 로그 우도**: 데이터를 가장 잘 설명하는 파라미터 찾기
- **NLL**: "우도 최대화 = 손실 최소화"로 바뀌는 핵심 변환
- ➡️ 손실 함수가 등장하는 수학적 이유를 제공

### 5. 손실 함수와 확률 분포의 연결
- **MSE ↔ 정규분포 오차 가정**
- **CrossEntropy ↔ 다항분포 + KL 발산**
- ➡️ 3장에서 학습한 손실 함수가 어떤 확률 모델 위에서 정의되는지 재확인

### 6. 베이즈 정리와 실전 활용
- **사전/사후 확률, 베이지안 최적화**: 불확실성까지 추적하고 싶은 경우의 확장판
- **MLE vs Bayesian**: 단일 추정 vs 분포 추정의 차이 이해

### 7. 배치 정규화 (Batch Normalization)
- **내부 공변량 이동** 문제를 통계적 표준화로 해결
- 평균 0, 분산 1로 맞춰 정규분포 상의 안정된 학습을 돕는 이유 설명

### 8. 실전 구현 (Part 3 노트북)
- 시각화로 평균/분산, 68-95-99.7 법칙 체감
- 인공 데이터로 MSE, CrossEntropy의 동작 확인
- 학습 루프, 배치 처리, 가정 검증, 이상치 실험까지 연결
- ➡️ 이론이 코드에서 어떻게 쓰이는지 한눈에 정리

## 전체 흐름 한눈에

`확률 공리` → `정보 이론(엔트로피·KL)` → `MLE` → `손실 함수(NLL)` → `PyTorch 구현`

- 앞단에서 세운 확률 가정이 손실 함수의 형태를 결정하고
- 손실 함수를 최소화하는 학습 과정이 다시 확률 모델을 추정합니다.
- Part 3의 시각화와 실험은 이 연결고리가 실제 코드에서 어떻게 구현되는지 보여주는 마지막 확인 단계였습니다.
