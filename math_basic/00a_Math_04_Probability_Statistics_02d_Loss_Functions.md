# 2.4 손실 함수
---

손실 함수(Loss Function)는 머신러닝 모델이 얼마나 잘못 예측했는지를 측정하는 함수다. 경사하강법(Gradient Descent)으로 이 손실을 줄여나가며 모델을 학습한다. 손실 함수는 단순한 수식이 아니라 확률론적 의미를 가지고 있으며, 특정 확률 분포의 가정에서 자연스럽게 유도된다.

## 0. 우도함수(Likelihood Function) 기초

손실 함수를 이해하기 전에, 우도함수(Likelihood Function)의 개념을 먼저 이해해야 한다. 우도함수는 최대우도추정(Maximum Likelihood Estimation, MLE)의 핵심이며, 손실 함수의 이론적 기반이 된다.

### Step 0: 우도(Likelihood)란 무엇인가?

**우도(Likelihood)**는 주어진 파라미터에서 특정 데이터가 관측될 가능성을 나타낸다. 확률(Probability)과 비슷해 보이지만 중요한 차이가 있다.

**기호 정리**:
- $\theta$ (세타, Theta): 모델의 파라미터(Parameter). 우리가 추정하고 싶은 값
- $y$ 또는 $\mathbf{y} = (y_1, y_2, \ldots, y_n)$: 관측된 데이터(Data)
- $P(y | \theta)$: 확률(Probability). 파라미터 $\theta$가 고정되어 있을 때 데이터 $y$가 나올 확률
- $L(\theta | y)$ 또는 $L(\theta)$: 우도함수(Likelihood Function). 데이터 $y$가 고정되어 있을 때 파라미터 $\theta$에 대한 함수

**확률과 우도의 차이**:
- **확률(Probability)**: 파라미터 $\theta$가 고정되어 있고, 데이터 $y$가 변수. "이 동전($p=0.5$)을 던졌을 때 앞면이 나올 확률은?"
- **우도(Likelihood)**: 데이터 $y$가 고정되어 있고, 파라미터 $\theta$가 변수. "앞면이 3번 나왔을 때, 이 동전의 앞면 확률 $p$는 얼마일까?"

### Step 1: 구체적 예시로 이해하기

**문제**: 동전을 5번 던져서 앞면이 3번, 뒷면이 2번 나왔다. 이 동전이 앞면이 나올 확률 $p$는 얼마일까?

이 질문 자체가 우도함수를 사용하는 문제다. 우리는 관측된 데이터(앞면 3번, 뒷면 2번)를 바탕으로 알 수 없는 파라미터 $p$를 추정해야 한다.

**Step 1-1: 각 시행의 확률**

동전을 한 번 던졌을 때:
- 앞면이 나올 확률: $P(\text{앞면} | p) = p$
- 뒷면이 나올 확률: $P(\text{뒷면} | p) = 1-p$

**Step 1-2: 전체 데이터가 나올 확률**

5번 던져서 앞면 3번, 뒷면 2번이 나올 확률은 (독립 시행이므로):

$$P(\text{앞면 3번, 뒷면 2번} | p) = p \times p \times p \times (1-p) \times (1-p) = p^3(1-p)^2$$

이것은 확률이다. $p$가 주어지면 이 데이터가 나올 확률을 계산할 수 있다.

**Step 1-3: 우도함수로 바꾸기**

하지만 우리의 문제는 반대다. 데이터는 이미 관측되었고(앞면 3번, 뒷면 2번), 우리는 $p$를 모른다. 이 경우 확률 $P(\text{데이터} | p)$를 파라미터 $p$에 대한 함수로 보면, 이것이 바로 **우도함수(Likelihood Function)**다:

$$L(p) = p^3(1-p)^2$$

**의미**: 
- $p = 0.5$일 때: $L(0.5) = 0.5^3 \times 0.5^2 = 0.03125$
- $p = 0.6$일 때: $L(0.6) = 0.6^3 \times 0.4^2 = 0.03456$
- $p = 0.7$일 때: $L(0.7) = 0.7^3 \times 0.3^2 = 0.03087$

$p = 0.6$일 때 우도가 가장 크다. 즉, $p = 0.6$일 때 이 데이터(앞면 3번, 뒷면 2번)가 가장 그럴듯하게 나온다.

**Step 1-4: 최대우도추정(MLE)**

우도를 최대화하는 $p$를 찾는 것이 최대우도추정(Maximum Likelihood Estimation, MLE)이다:

$$\hat{p}_{MLE} = \arg\max_p L(p) = \arg\max_p p^3(1-p)^2$$

이 문제의 답은 $\hat{p}_{MLE} = \frac{3}{5} = 0.6$이다. (나중에 미분으로 구하는 방법을 배운다)

### Step 2: 우도함수의 일반적 정의

일반적으로 $n$개의 독립적인 관측값 $y_1, y_2, \ldots, y_n$이 주어졌을 때, 우도함수는:

$$L(\theta | \mathbf{y}) = \prod_{i=1}^n P(y_i | \theta)$$

여기서:
- $\prod$ (파이, Pi): 곱하기 기호. $\prod_{i=1}^n a_i = a_1 \times a_2 \times \cdots \times a_n$
- $P(y_i | \theta)$: 파라미터 $\theta$가 주어졌을 때 $y_i$가 관측될 확률

**왜 곱하기인가?**
- 각 관측값이 독립적이므로, 모든 관측값이 동시에 나올 확률은 각 확률의 곱이다.
- 동전을 3번 던져 모두 앞면이 나올 확률 = $\frac{1}{2} \times \frac{1}{2} \times \frac{1}{2} = \frac{1}{8}$

**표기 관례**:
- $L(\theta | y)$: 데이터 $y$가 주어졌을 때 파라미터 $\theta$에 대한 우도함수
- 간단히 $L(\theta)$로 표기하기도 한다 (데이터는 이미 관측되었으므로 생략)
- 때로는 데이터 관점에서 $L(y)$로 표기하기도 하지만, 이는 혼란을 줄 수 있으므로 $L(\theta)$ 또는 $L(\theta | y)$를 사용하는 것이 일반적이다

### Step 3: 로그 우도(Log-Likelihood)

우도함수는 여러 확률의 곱이므로 매우 작은 값이 될 수 있다. 수치적으로 불안정하므로 로그를 취해 덧셈 형태로 변환한다:

$$\ell(\theta) = \log L(\theta) = \sum_{i=1}^n \log P(y_i | \theta)$$

**왜 로그를 취하는가?**
1. **수치적 안정성**: 곱셈이 덧셈으로 변해 언더플로(underflow) 방지
2. **계산 편의성**: 로그는 단조증가 함수이므로, 우도를 최대화하는 것과 로그 우도를 최대화하는 것은 동일
3. **미분 편의성**: 곱의 미분보다 합의 미분이 훨씬 간단

**최대우도추정의 목표**:
$$\hat{\theta}_{MLE} = \arg\max_\theta L(\theta) = \arg\max_\theta \ell(\theta)$$

### Step 4: 우도함수와 손실 함수의 연결

머신러닝에서는 최적화 알고리즘이 보통 **최소화** 문제로 구현되어 있다. 따라서 음의 로그 우도(Negative Log-Likelihood, NLL)를 손실 함수로 사용한다:

$$\text{Loss}(\theta) = -\ell(\theta) = -\sum_{i=1}^n \log P(y_i | \theta)$$

**의미**:
- 손실을 최소화 = 로그 우도를 최대화 = 우도를 최대화
- 경사하강법으로 이 손실을 줄여나가면, 결국 우도를 최대화하는 파라미터를 찾게 된다

**요약**:
- **우도(Likelihood)**: 주어진 파라미터에서 데이터가 나올 가능성
- **우도함수**: 데이터가 고정되어 있을 때 파라미터에 대한 함수
- **최대우도추정(MLE)**: 우도를 최대화하는 파라미터를 찾는 방법
- **손실 함수**: 음의 로그 우도. MLE를 최소화 문제로 변환한 것

## 1. 평균 제곱 오차 손실 (Mean Squared Error, MSE Loss) ↔ 정규 분포 (Normal Distribution)

**언제 쓰나요?** 입력 $x$가 주어졌을 때 실수 값 $y$를 예측하는 회귀(Regression) 문제에서 가장 널리 쓰는 손실 함수다.

### Step 0: 기호 정리 및 문제 설정

**기호 정리**:
- $n$: 데이터 포인트의 개수
- $(x_i, y_i)$: $i$번째 관측 쌍. $x_i$는 입력(Input), $y_i$는 실제 값(True value)
- $\hat{y}_i = f(x_i; \theta)$: 모델의 예측값(Prediction). $f$는 모델 함수(신경망, 선형 회귀 등), $\theta$는 모델 파라미터
- $\epsilon_i = y_i - \hat{y}_i = y_i - f(x_i; \theta)$: 오차(Error). 실제 값과 예측값의 차이
- $\mu$ (뮤, Mu): 평균(Mean)
- $\sigma^2$ (시그마 제곱, Sigma squared): 분산(Variance)

**문제**: 왜 MSE를 사용하는가? 단순히 "오차의 제곱"이 아니라, 통계적으로 정당화된 이유가 있다.

### Step 1: 가정 - 오차가 정규분포를 따른다

회귀 모델에서 실제 값과 예측값의 차이를 오차(Error)라고 한다:

$$y_i = f(x_i; \theta) + \epsilon_i$$

여기서 오차 $\epsilon_i$는 여러 작은 교란의 합으로 볼 수 있다. 중심극한정리(Central Limit Theorem)에 의해, 많은 작은 교란의 합은 정규분포에 가까워진다. 따라서 다음과 같이 가정한다:

$$\epsilon_i \sim \mathcal{N}(0, \sigma^2)$$

즉, 오차는 평균 0, 분산 $\sigma^2$인 정규분포를 따른다.

**왜 평균 0인가?**
- 모델이 완벽하다면 오차의 평균은 0이어야 한다
- 양의 오차와 음의 오차가 균형을 이룬다

**왜 정규분포인가?**
- 많은 작은 교란의 합 → 중심극한정리에 의해 정규분포로 근사
- 실제 측정 오차가 정규분포로 모델링되는 경우가 많음
- 물론 항상 맞지는 않지만 "가장 먼저 시도해 볼 만한" 합리적 출발점이다

### Step 2: 한 데이터 포인트의 확률

오차가 정규분포를 따르므로, 실제 값 $y_i$도 정규분포를 따른다:

$$y_i \sim \mathcal{N}(f(x_i; \theta), \sigma^2)$$

즉, $y_i$는 평균 $f(x_i; \theta)$, 분산 $\sigma^2$인 정규분포를 따른다.

정규분포의 확률 밀도 함수(Probability Density Function, PDF)는:

$$P(y_i | x_i, \theta) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(y_i - f(x_i; \theta))^2}{2\sigma^2}\right)$$

**의미**:
- $f(x_i; \theta)$가 예측한 값 근처일수록 확률(우도)이 커진다
- 멀리 떨어질수록 지수 함수가 급격히 감소한다
- $(y_i - f(x_i; \theta))^2$: 예측값과 실제 값의 차이의 제곱. 이것이 바로 "제곱 오차"다

**왜 평균값을 빼는가?**
- $(y_i - f(x_i; \theta))$는 "중심(평균)으로부터의 거리"를 나타낸다
- 정규분포는 중심에서 멀어질수록 확률이 급격히 감소한다
- 제곱을 하는 이유: 양의 오차와 음의 오차를 모두 고려하기 위함

### Step 3: 전체 데이터의 우도함수

데이터 포인트들이 서로 독립이라고 가정하면, 모든 데이터가 동시에 나올 확률은 각 확률의 곱이다:

$$L(\theta) = \prod_{i=1}^n P(y_i | x_i, \theta) = \prod_{i=1}^n \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(y_i - f(x_i; \theta))^2}{2\sigma^2}\right)$$

**왜 곱하기인가?**
- 각 데이터 포인트가 독립적으로 발생한다고 가정
- 독립 사건이 동시에 일어날 확률 = 각 확률의 곱
- 예: 동전을 3번 던져 모두 앞면이 나올 확률 = $\frac{1}{2} \times \frac{1}{2} \times \frac{1}{2}$

### Step 4: 로그 우도로 변환

로그를 취하면 곱셈이 덧셈으로 변환된다:

$$\ell(\theta) = \log L(\theta) = \sum_{i=1}^n \log \left( \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(y_i - f(x_i; \theta))^2}{2\sigma^2}\right) \right)$$

로그의 성질을 사용하면:

$$\ell(\theta) = \sum_{i=1}^n \left[ -\frac{1}{2}\log(2\pi\sigma^2) - \frac{(y_i - f(x_i; \theta))^2}{2\sigma^2} \right]$$

$$= -\frac{n}{2}\log(2\pi\sigma^2) - \frac{1}{2\sigma^2}\sum_{i=1}^n (y_i - f(x_i; \theta))^2$$

**의미**:
- 첫 번째 항 $-\frac{n}{2}\log(2\pi\sigma^2)$: 파라미터 $\theta$와 무관한 상수 (최적화와 무관)
- 두 번째 항 $-\frac{1}{2\sigma^2}\sum_{i=1}^n (y_i - f(x_i; \theta))^2$: 우리가 익숙한 "제곱 오차의 합"

### Step 5: 손실 함수로 변환

최대우도추정의 목표는 우도를 최대화하는 것이다:

$$\hat{\theta}_{MLE} = \arg\max_\theta \ell(\theta)$$

$\sigma^2$가 고정되어 있다면, 첫 번째 항은 상수이므로 무시할 수 있다:

$$\arg\max_\theta \ell(\theta) = \arg\max_\theta \left[ -\frac{1}{2\sigma^2}\sum_{i=1}^n (y_i - f(x_i; \theta))^2 \right]$$

음수와 상수 $\frac{1}{2\sigma^2}$를 제거하면:

$$= \arg\min_\theta \sum_{i=1}^n (y_i - f(x_i; \theta))^2$$

상수를 떼고 $\frac{1}{n}$으로 평균을 내면 바로 MSE가 된다:

$$\text{MSE}(\theta) = \frac{1}{n} \sum_{i=1}^n (y_i - f(x_i; \theta))^2$$

**요약**:
- 정규분포 가정 → 제곱 오차가 자연스럽게 등장
- 우도를 최대화하는 것 = MSE를 최소화하는 것
- "예측이 실제값과 얼마나 떨어져 있는가"를 제곱으로 측정하는 이유가 통계적으로 정당화된다

## 2. 교차 엔트로피 손실 (CrossEntropy Loss) ↔ 다항 분포 (Multinomial Distribution) + 정보 이론

**언제 쓰나요?** 여러 클래스 중 하나를 예측해야 하는 분류(Classification) 문제에서 표준으로 쓰이는 손실 함수다.

### Step 0: 기호 정리 및 문제 설정

**기호 정리**:
- $K$: 클래스(Class)의 개수
- $y_i$: $i$번째 데이터의 실제 레이블(Label). one-hot 벡터 형태: $y_i = [y_{i,1}, y_{i,2}, \ldots, y_{i,K}]$
  - one-hot 벡터: 정답 클래스만 1, 나머지는 0. 예: $[0, 1, 0]$ (2번째 클래스가 정답)
- $y_{i,k}$: $i$번째 데이터가 $k$번째 클래스일 확률 (one-hot이므로 0 또는 1)
- $\hat{p}_i = [\hat{p}_{i,1}, \hat{p}_{i,2}, \ldots, \hat{p}_{i,K}]$: 모델이 예측한 확률 분포. 소프트맥스(Softmax) 출력
  - $\sum_{k=1}^K \hat{p}_{i,k} = 1$ (확률의 합은 1)
- $\hat{p}_{i,k}$: 모델이 $i$번째 데이터를 $k$번째 클래스로 예측할 확률

**문제**: 왜 CrossEntropy를 사용하는가? 정보 이론과 통계학(MLE) 두 관점에서 모두 정당화된다.

### Step 1: 정보 이론 관점

교차 엔트로피(Cross-Entropy)는 "정답 분포 $P$"를 "모델 분포 $Q$"로 코딩할 때 필요한 평균 정보량이다.

$$H(P, Q) = -\sum_{k=1}^K y_{i,k} \log \hat{p}_{i,k}$$

**의미**:
- $y_{i,k}$: 실제 분포 (one-hot이므로 정답 클래스만 1)
- $\hat{p}_{i,k}$: 모델이 예측한 분포
- $-\log \hat{p}_{i,k}$: $k$번째 클래스를 코딩하는데 필요한 정보량
- 정답 클래스 하나만 1이므로 실질적으로는 $-\log \hat{p}_{i,k^*}$만 남는다 ($k^*$는 정답 클래스)

**직관**:
- $\hat{p}_{i,k^*}$가 커질수록(정답을 더 확신할수록) 손실이 작아진다
- $\hat{p}_{i,k^*}$가 작을수록(정답을 틀릴수록) 손실이 커진다
- $H(P, Q) = H(P) + D_{KL}(P||Q)$ → 정답 분포의 엔트로피 $H(P)$는 고정이므로, 교차 엔트로피를 줄이는 것은 KL 발산을 줄이는 것과 동일하다

### Step 2: MLE 관점

레이블이 다항 분포(Multinomial Distribution)를 따른다고 보면, 한 데이터의 확률은:

$$P(y_i | x_i, \theta) = \prod_{k=1}^K (\hat{p}_{i,k})^{y_{i,k}}$$

**의미**:
- one-hot 벡터에서 $y_{i,k} = 1$인 정답 클래스 $k^*$만 남고 나머지는 $y_{i,k} = 0$이다
- 정답 클래스 $k^*$: $(\hat{p}_{i,k^*})^{1} = \hat{p}_{i,k^*}$
- 나머지 클래스 $k \neq k^*$: $(\hat{p}_{i,k})^{0} = 1$ (어떤 수의 0제곱은 1)

따라서:

$$P(y_i | x_i, \theta) = \hat{p}_{i,k^*}$$

한 데이터의 로그 우도는:

$$\log P(y_i | x_i, \theta) = \log \hat{p}_{i,k^*} = \sum_{k=1}^K y_{i,k} \log \hat{p}_{i,k}$$

**이유**: 
- 정답 클래스 $k^*$: $y_{i,k^*} = 1$이므로 $1 \cdot \log(\hat{p}_{i,k^*}) = \log(\hat{p}_{i,k^*})$
- 나머지 클래스 $k \neq k^*$: $y_{i,k} = 0$이므로 $0 \cdot \log(\hat{p}_{i,k}) = 0$
- 따라서 합은 정답 클래스의 로그 확률만 남는다

전체 데이터에 대한 로그 우도는:

$$\ell(\theta) = \sum_{i=1}^n \log P(y_i | x_i, \theta) = \sum_{i=1}^n \sum_{k=1}^K y_{i,k} \log \hat{p}_{i,k}$$

**참고**: 수학적으로 $0 \cdot \log(0) = 0$으로 정의한다 (극한값).

### Step 3: 손실 함수로 변환

최대우도추정의 목표는 로그 우도를 최대화하는 것이다:

$$\hat{\theta}_{MLE} = \arg\max_\theta \sum_{i=1}^n \sum_{k=1}^K y_{i,k} \log \hat{p}_{i,k}$$

최대화 문제를 최소화 문제로 변환하면:

$$\arg\max_\theta \sum_{i=1}^n \sum_{k=1}^K y_{i,k} \log \hat{p}_{i,k} = \arg\min_\theta \left( -\sum_{i=1}^n \sum_{k=1}^K y_{i,k} \log \hat{p}_{i,k} \right)$$

**결론**: CrossEntropy Loss가 등장한다!

$$\text{CrossEntropy} = -\frac{1}{n}\sum_{i=1}^n \sum_{k=1}^K y_{i,k} \log \hat{p}_{i,k}$$

**핵심 통찰**: 
- 로그 우도를 최대화 = CrossEntropy를 최소화
- 정답 클래스의 예측 확률이 높을수록 로그 우도가 커지고 손실이 감소
- 이것이 정보 이론의 CrossEntropy와 동일한 형태!

### Step 4: 두 관점의 통합

**정보 이론 관점**: 실제 분포와 모델 분포의 차이(정보 손실)를 최소화

**통계/MLE 관점**: 데이터가 나올 가능성이 최대가 되도록 파라미터 학습

결국 둘 다 같은 식으로 귀결되며, 손실이 작을수록 모델 확률 $\hat{p}$가 정답 분포 $y$에 가까워진다는 것을 의미한다.

**이름의 의미**: 실제 분포(정답)와 예측 분포가 서로 "교차"하는 방식으로 엔트로피를 측정하기 때문에 Cross + Entropy라고 부른다.

## 3. MLE 구체적 계산 예시

이제 실제 데이터를 사용해 우도함수 → 로그 우도 → 미분 → 해 구하는 전체 과정을 단계별로 살펴본다.

### 예시 1: 정규분포 평균 $\mu$ 추정 (분산은 알려져 있다고 가정)

**문제**: 시험 점수 [85, 90, 88, 92]를 관측했다. 평균 $\mu$는 얼마일까? (분산 $\sigma^2 = 4$는 이미 알고 있다고 가정)

**Step 0: 기호 정리**
- 관측 데이터: $y_1 = 85, y_2 = 90, y_3 = 88, y_4 = 92$
- 가정: $y_i \sim \mathcal{N}(\mu, \sigma^2)$, 여기서 $\sigma^2 = 4$는 이미 알고 있음
- 질문: "어떤 $\mu$여야 지금 데이터를 가장 잘 설명할까?"

**Step 1: 우도함수 작성**

한 데이터 포인트의 확률:

$$P(y_i | \mu) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(y_i - \mu)^2}{2\sigma^2}\right) = \frac{1}{\sqrt{8\pi}} \exp\left(-\frac{(y_i - \mu)^2}{8}\right)$$

독립성이 있으니 곱으로 합친다:

$$L(\mu) = \prod_{i=1}^4 P(y_i | \mu) = \prod_{i=1}^4 \frac{1}{\sqrt{8\pi}} \exp\left(-\frac{(y_i - \mu)^2}{8}\right)$$

**Step 2: 로그 우도로 단순화**

로그를 취하면:

$$\ell(\mu) = \log L(\mu) = \sum_{i=1}^4 \left[ -\frac{1}{2}\log(8\pi) - \frac{(y_i - \mu)^2}{8} \right]$$

$$= -2\log(8\pi) - \frac{1}{8} \sum_{i=1}^4 (y_i - \mu)^2$$

**의미**:
- 첫 항 $-2\log(8\pi)$: $\mu$와 무관한 상수 (최적화와 무관)
- 두 번째 항 $-\frac{1}{8} \sum_{i=1}^4 (y_i - \mu)^2$: 제곱 오차의 합

**Step 3: 미분과 의미 해석**

로그 우도를 $\mu$에 대해 미분하면:

$$\frac{d}{d\mu} \ell(\mu) = \frac{d}{d\mu} \left[ -2\log(8\pi) - \frac{1}{8} \sum_{i=1}^4 (y_i - \mu)^2 \right]$$

첫 항은 상수이므로 미분하면 0이다. 두 번째 항을 미분하면:

$$\frac{d}{d\mu} \left[ -\frac{1}{8} \sum_{i=1}^4 (y_i - \mu)^2 \right] = -\frac{1}{8} \sum_{i=1}^4 \frac{d}{d\mu}(y_i - \mu)^2$$

$(y_i - \mu)^2$를 $\mu$에 대해 미분하면:
- $(y_i - \mu)^2$를 $u = y_i - \mu$로 치환하면 $u^2$의 미분은 $2u$
- 체인 룰에 의해 $\frac{d}{d\mu} = \frac{d}{du} \cdot \frac{du}{d\mu} = 2u \cdot (-1) = -2(y_i - \mu)$

따라서:

$$\frac{d}{d\mu} \ell(\mu) = -\frac{1}{8} \sum_{i=1}^4 [-2(y_i - \mu)] = \frac{1}{4} \sum_{i=1}^4 (y_i - \mu)$$

**의미**:
- $\sum_{i=1}^4 (y_i - \mu)$: "데이터와 현재 평균의 차이들의 합"
- 이 값이 양수면: 데이터가 평균보다 크므로 $\mu$를 키워야 함
- 이 값이 음수면: 데이터가 평균보다 작으므로 $\mu$를 줄여야 함
- 이 값이 0이면: 균형 상태. 우도가 최대

**Step 4: 극값 구하기**

기울기를 0으로 두면:

$$\frac{1}{4} \sum_{i=1}^4 (y_i - \mu) = 0$$

$$\sum_{i=1}^4 (y_i - \mu) = 0$$

$$\sum_{i=1}^4 y_i - 4\mu = 0$$

$$\mu = \frac{1}{4} \sum_{i=1}^4 y_i = \bar{y}$$

**결과**:

$$\hat{\mu}_{MLE} = \frac{85 + 90 + 88 + 92}{4} = \frac{355}{4} = 88.75$$

**해석**:
- 정규분포 평균의 MLE는 항상 샘플 평균과 일치한다
- "데이터의 중심"이 곧 가장 그럴듯한 평균이라는 직관과 딱 맞아떨어진다

### 예시 2: 베르누이 성공 확률 $p$ 추정

**문제**: 동전을 5번 던져서 앞면이 3번, 뒷면이 2번 나왔다. 이 동전이 앞면이 나올 확률 $p$는 얼마일까?

**Step 0: 기호 정리**
- 관측 데이터: $[1, 0, 1, 1, 0]$ (1 = 성공/앞면, 0 = 실패/뒷면)
- 가정: 매 시행은 독립이고 성공 확률 $p$가 일정함
- 질문: "이 동전이 앞면이 나올 확률은 얼마일까?"

**Step 1: 우도함수 작성**

한 시행의 확률:

$$P(x_i | p) = p^{x_i}(1-p)^{1-x_i}$$

- $x_i=1$일 때는 $p$
- $x_i=0$일 때는 $1-p$

독립 시행 5번을 곱하면:

$$L(p) = \prod_{i=1}^5 P(x_i | p) = \prod_{i=1}^5 p^{x_i}(1-p)^{1-x_i}$$

앞면 3번($x_i=1$), 뒷면 2번($x_i=0$)이므로:

$$L(p) = p \times (1-p) \times p \times p \times (1-p) = p^3(1-p)^2$$

**의미**:
- 앞면 3번 → $p^3$
- 뒷면 2번 → $(1-p)^2$

**Step 2: 로그 우도**

로그를 취하면:

$$\ell(p) = \log L(p) = \log[p^3(1-p)^2] = 3\log p + 2\log(1-p)$$

**Step 3: 미분과 힘의 균형 이해**

로그 우도를 $p$에 대해 미분하면:

$$\frac{d}{dp} \ell(p) = \frac{d}{dp}[3\log p + 2\log(1-p)]$$

$$= 3 \cdot \frac{1}{p} + 2 \cdot \frac{1}{1-p} \cdot (-1)$$

$$= \frac{3}{p} - \frac{2}{1-p}$$

**직관적 해석 - 두 힘의 균형**:

이 미분값은 두 가지 힘의 균형을 나타낸다:

1. **$\frac{3}{p}$**: 성공 3번이 "$p$를 키우자"고 당기는 힘
   - $p$가 작을수록 이 힘이 커진다 (분모가 작으므로)
   - 성공이 많았으므로 $p$를 높여야 한다는 신호

2. **$-\frac{2}{1-p}$**: 실패 2번이 "$p$를 줄이자"고 말리는 힘
   - $p$가 클수록 이 힘이 커진다 (분모 $1-p$가 작으므로)
   - 실패가 있었으므로 $p$를 낮춰야 한다는 신호

**왜 두 힘이 균형을 이루는 지점을 찾기 위해 0으로 두는가?**

미분값이 0인 지점은 두 힘이 정확히 균형을 이루는 지점이다:
- 미분값 > 0: "$p$를 키우자"는 힘이 더 크다 → $p$를 키우면 우도가 증가
- 미분값 < 0: "$p$를 줄이자"는 힘이 더 크다 → $p$를 줄이면 우도가 증가
- 미분값 = 0: 두 힘이 균형 → 더 이상 우도를 키울 수 없다 = 우도가 최대

**일반적 원리**:
- 미분 = 기울기
- 기울기가 0인 지점 = 극값(최대 또는 최소)
- 로그 우도는 위로 볼록한 함수이므로, 기울기가 0인 지점에서 최대가 된다

**Step 4: 극값 구하기**

두 힘이 균형을 이루는 지점을 찾기 위해 미분을 0으로 둔다:

$$\frac{3}{p} - \frac{2}{1-p} = 0$$

$$\frac{3}{p} = \frac{2}{1-p}$$

양변에 $p(1-p)$를 곱하면:

$$3(1-p) = 2p$$

$$3 - 3p = 2p$$

$$3 = 5p$$

$$p = \frac{3}{5} = 0.6$$

**결과**:

$$\hat{p}_{MLE} = \frac{3}{5} = 0.6$$

**해석**:
- MLE는 "성공 횟수 / 전체 시행"과 같다
- 데이터가 말해 주는 그대로 앞면 비율이 60%였으니, 모델도 0.6으로 학습되는 게 가장 자연스럽다

**일반화**:
- $n$번 중 성공이 $k$번이면 $\hat{p}_{MLE} = \frac{k}{n}$
- 결국 베르누이의 MLE도 정규분포 사례처럼 "샘플이 보여주는 평균 행동"을 그대로 받아들이는 추정법이다

## 4. MLE 추정량의 통계적 성질

**질문**: MLE로 구한 추정량 $\hat{\theta}_{MLE}$는 어떤 좋은 성질을 가지고 있을까?

### 4.1 일관성 (Consistency)

**정의**: 샘플 크기 $n$이 무한대로 갈 때, MLE 추정량이 참값 $\theta$에 확률적으로 수렴한다.

$$\hat{\theta}_{MLE} \xrightarrow{p} \theta \quad \text{as } n \to \infty$$

**의미**: 
- 데이터가 많을수록 MLE 추정값이 참값에 가까워진다
- "큰 수의 법칙"과 유사한 개념

**직관적 이해**:
- 동전을 10번 던져서 앞면이 6번 나왔다면: $\hat{p} = 0.6$
- 동전을 100번 던져서 앞면이 55번 나왔다면: $\hat{p} = 0.55$ (더 정확)
- 동전을 1000번 던지면: $\hat{p}$가 실제 $p$에 더 가까워진다

**머신러닝 연결**:
- 더 많은 데이터를 사용할수록 모델 파라미터 추정이 정확해진다
- 이것이 "데이터가 많을수록 좋다"는 말의 이론적 근거

### 4.2 비편향성 (Unbiasedness)

**정의**: MLE 추정량의 기댓값이 참값과 같을 때 **비편향 (Unbiased)**이라고 한다.

$$E[\hat{\theta}_{MLE}] = \theta$$

**기호 설명**:
- $E[\cdot]$: 기댓값(Expectation). 확률변수의 평균값
- $\hat{\theta}_{MLE}$: MLE로 구한 추정량(Estimator). 데이터의 함수이므로 확률변수
- $\theta$: 참값(True parameter). 우리가 알고 싶은 실제 파라미터 값

**주의**: MLE가 항상 비편향인 것은 아니다!

**비편향인 경우**:

1. **정규분포의 평균**: 
   $$\hat{\mu}_{MLE} = \bar{X} = \frac{1}{n}\sum_{i=1}^n X_i$$
   
   기댓값을 계산하면:
   $$E[\hat{\mu}_{MLE}] = E\left[\frac{1}{n}\sum_{i=1}^n X_i\right] = \frac{1}{n}\sum_{i=1}^n E[X_i] = \frac{1}{n} \cdot n \cdot \mu = \mu$$
   
   따라서 $E[\hat{\mu}_{MLE}] = \mu$ ✓ (비편향)

2. **베르누이 분포**: 
   $$\hat{p}_{MLE} = \frac{k}{n} = \frac{1}{n}\sum_{i=1}^n X_i$$
   
   여기서 $k$는 성공 횟수, $X_i$는 $i$번째 시행의 결과(1 또는 0)
   
   기댓값을 계산하면:
   $$E[\hat{p}_{MLE}] = E\left[\frac{1}{n}\sum_{i=1}^n X_i\right] = \frac{1}{n}\sum_{i=1}^n E[X_i] = \frac{1}{n} \cdot n \cdot p = p$$
   
   따라서 $E[\hat{p}_{MLE}] = p$ ✓ (비편향)

**편향된 경우**:

**정규분포의 분산**: 
$$\hat{\sigma}^2_{MLE} = \frac{1}{n}\sum_{i=1}^n (X_i - \bar{X})^2$$

기댓값을 계산하면 (자세한 유도는 생략):

$$E[\hat{\sigma}^2_{MLE}] = \frac{n-1}{n}\sigma^2 \neq \sigma^2$$

**의미**:
- MLE 추정량은 평균적으로 참값보다 약간 작다
- 보통 $\frac{1}{n-1}$을 사용하는 표본 분산(Sample Variance)이 비편향:
  $$s^2 = \frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X})^2$$
  $$E[s^2] = \sigma^2$$ ✓ (비편향)

**의미**:
- 비편향: 평균적으로 참값을 맞춘다
- 편향: 평균적으로 참값에서 벗어난다
- 하지만 일관성이 있으면 큰 샘플에서 편향이 사라진다 ($\lim_{n \to \infty} \frac{n-1}{n} = 1$)

**머신러닝 연결**:
- 편향이 있으면 모델이 체계적으로 특정 방향으로 틀릴 수 있다
- 하지만 일관성이 있으면 큰 샘플에서 편향이 사라진다

### 4.3 효율성 (Efficiency)

**정의**: MLE는 **점근적으로 효율적 (Asymptotically Efficient)**이다.

**의미**:
- 큰 샘플에서 MLE는 **최소 분산**을 가진다
- 다른 추정량보다 더 정확하다 (분산이 작음)

**Cramér-Rao 하한 (Cramér-Rao Lower Bound, CRLB)**:
- 어떤 비편향 추정량도 가질 수 있는 최소 분산의 하한
- MLE는 큰 샘플에서 이 하한에 도달한다

**Fisher 정보량 (Fisher Information) $I(\theta)$**:

Fisher 정보량은 분포가 파라미터에 대해 얼마나 많은 정보를 담고 있는지를 나타낸다:

$$I(\theta) = E\left[\left(\frac{\partial \log P(X|\theta)}{\partial \theta}\right)^2\right]$$

**의미**:
- 정보량이 클수록 파라미터를 더 정확하게 추정할 수 있다
- 정보량이 작을수록 파라미터 추정이 불확실하다

**MLE의 분산**:

큰 샘플에서 MLE의 분산은:

$$\text{Var}(\hat{\theta}_{MLE}) \approx \frac{1}{nI(\theta)}$$

**직관적 이해**:
- 정보가 많을수록($I(\theta)$가 클수록) 분산이 작아진다
- 샘플 크기가 클수록($n$이 클수록) 분산이 작아진다
- 여러 추정 방법 중에서 MLE가 가장 정확하다

**머신러닝 연결**:
- MLE를 사용하는 것이 통계적으로 가장 효율적이다
- 이것이 MLE가 널리 사용되는 이유 중 하나다

### 4.4 점근적 정규성 (Asymptotic Normality)

**정의**: 큰 샘플에서 MLE 추정량은 정규분포를 따른다.

$$\hat{\theta}_{MLE} \sim \mathcal{N}\left(\theta, \frac{1}{nI(\theta)}\right) \quad \text{as } n \to \infty$$

**의미**:
- 샘플 크기가 클수록 MLE 추정량이 정규분포에 가까워진다
- 평균은 참값 $\theta$, 분산은 $\frac{1}{nI(\theta)}$

**Fisher 정보량**:
- 분포의 정보를 담고 있는 양
- 정보가 많을수록 (불확실성이 적을수록) 분산이 작아진다

**직관적 이해**:
- 중심극한정리(Central Limit Theorem)와 유사: 많은 확률변수의 합이 정규분포에 가까워진다
- MLE도 많은 데이터의 함수이므로 정규분포에 가까워진다

**머신러닝 연결**:
- 신뢰 구간(Confidence Interval) 계산 가능
- 가설 검정(Hypothesis Testing) 가능
- 불확실성 정량화 가능

**구체적 예시**:

1. **정규분포의 평균 추정**:
   $$\hat{\mu}_{MLE} = \bar{X} \sim \mathcal{N}\left(\mu, \frac{\sigma^2}{n}\right)$$
   - 샘플 크기가 클수록 분산이 작아진다 ($\frac{\sigma^2}{n}$)

2. **베르누이 분포의 파라미터 추정**:
   $$\hat{p}_{MLE} = \frac{k}{n} \sim \mathcal{N}\left(p, \frac{p(1-p)}{n}\right) \quad \text{(큰 샘플에서)}$$
   - 샘플 크기가 클수록 분산이 작아진다

**요약**:

| 성질 | 정의 | 의미 |
|------|------|------|
| **일관성** | $\hat{\theta}_{MLE} \xrightarrow{p} \theta$ | 데이터가 많을수록 참값에 수렴 |
| **비편향성** | $E[\hat{\theta}_{MLE}] = \theta$ | 평균적으로 참값을 맞춤 (항상은 아님) |
| **효율성** | 최소 분산 | 가장 정확한 추정량 |
| **점근적 정규성** | 정규분포 근사 | 신뢰 구간, 가설 검정 가능 |

**머신러닝에서의 의미**:
- MLE는 통계적으로 우수한 성질을 가진 추정 방법이다
- 이것이 손실 함수 (MSE, CrossEntropy)의 이론적 기반이다
- 더 많은 데이터를 사용할수록 더 정확한 모델 학습이 가능하다

## 핵심 통찰

**손실 함수는 확률 분포의 가정에서 자연스럽게 유도된다!**

**이게 왜 중요한가?** 
손실 함수는 그냥 만든 게 아니라, "데이터가 이 확률 분포를 따른다"고 가정하고 그 가정에서 나온 것이다.

- **MSE**: 오차가 정규분포 (Normal Distribution)를 따른다고 가정 → 제곱 오차가 자연스럽게 나타남
- **CrossEntropy**: 레이블이 다항분포 (Multinomial Distribution)를 따른다고 가정 → 로그 확률이 자연스럽게 나타남

**따라서**:
- 회귀 문제에 MSE를 쓰는 건, 오차가 정규분포라는 합리적 가정 때문이다
- 분류 문제에 CrossEntropy를 쓰는 건, 레이블이 다항분포라는 합리적 가정 때문이다

## 배치 정규화 (Batch Normalization)와 정규 분포

**한 줄 소개**: 학습 중 계속 흔들리는 활성값의 분포를 매 미니배치마다 "평균 0, 분산 1"에 가깝게 재조정해 주는 기법이다.

### 1. 왜 필요한가? (Internal Covariate Shift)
- 이전 층의 파라미터가 업데이트되면, 다음 층이 받는 입력 분포가 달라진다
- 매번 새 분포에 적응해야 하니 학습이 불안정하고 느려진다
- 특히 활성화 함수가 포화되는 구간(sigmoid, tanh 등)에서 문제가 크게 나타난다

### 2. 배치 정규화의 수식

미니배치 $B = \{x_1, \ldots, x_m\}$에 대해

**기호 정리**:
- $m$: 미니배치 크기(Batch size)
- $x_i$: $i$번째 활성값
- $\mu_B$: 미니배치 평균(Batch mean)
- $\sigma_B^2$: 미니배치 분산(Batch variance)
- $\epsilon$: 0으로 나누는 사고를 막기 위한 아주 작은 값 (보통 $10^{-5}$)
- $\gamma$ (감마, Gamma): 학습 가능한 스케일 파라미터(Scale parameter)
- $\beta$ (베타, Beta): 학습 가능한 시프트 파라미터(Shift parameter)

**계산 과정**:

1. 미니배치 평균 계산:
$$\mu_B = \frac{1}{m} \sum_{i=1}^m x_i$$

2. 미니배치 분산 계산:
$$\sigma_B^2 = \frac{1}{m} \sum_{i=1}^m (x_i - \mu_B)^2$$

3. 표준화(Normalization):
$$\hat{x}_i = \frac{x_i - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}}$$

4. 스케일과 시프트 복원:
$$y_i = \gamma \hat{x}_i + \beta$$

**의미**:
- $\hat{x}_i$: 평균 0, 분산 1에 가깝게 정규화된 값
- $\gamma$: 얼마나 크게 키울지 (scale)
- $\beta$: 어디로 이동시킬지 (shift)
- $\epsilon$: 0으로 나누는 사고를 막기 위한 아주 작은 값

### 3. 통계적 해석
- $\hat{x}_i$는 평균 0, 분산 1에 가깝게 정규화된 값 → 표준 정규분포에 근사
- 이렇게 맞춰 놓으면 다음 층은 항상 비슷한 분포의 입력을 받기 때문에 학습이 안정적이다
- $\gamma$, $\beta$ 덕분에 모델이 원래 필요로 하는 분포 모양은 다시 복원할 수 있다 (정보 손실 없음)

### 4. 학습/추론 시 통계량 사용법
- **학습 중**: 현재 미니배치에서 계산한 $\mu_B$, $\sigma_B^2$ 사용
- **추론 시**: 학습 과정에서 누적해 둔 이동 평균 $\mu_{\text{running}}$, $\sigma^2_{\text{running}}$ 사용
  - 예: $\mu_{\text{running}} \leftarrow \alpha \mu_{\text{running}} + (1-\alpha) \mu_B$
  - 여기서 $\alpha$는 이동 평균 계수(보통 0.9 또는 0.99)
- 배치 크기가 1이어도 안정적으로 추론 가능

### 5. 기대 효과
- 학습률을 더 높게 설정해도 수렴이 빠르고 안정적이다
- 초기화에 덜 민감하다
- 그래디언트 소실/폭발 완화
- 결국 "각 층이 받는 입력을 표준 정규분포 근처로 유지"한다는 점에서 통계적 의미가 분명하다
